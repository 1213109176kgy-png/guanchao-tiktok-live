# 观潮 Guanchao v0.3.0

## 中文

首个公开发行版本：Windows 本地 TikTok 直播观众工作台。

- 内嵌 TikTok 首页，识别直播页面并快捷添加采集任务。
- 最多 3 个并行任务，提供观众筛选、等级记录、实时互动、人工跟进与 CSV 导出。
- 本机 SQLite 保存，代理和签名密钥通过运行设置配置。
- 清理所有产品演示入口，统一使用真实采集数据。

下载 Guanchao-0.3.0-Windows-x64.exe 双击运行，或完整解压 ZIP 后运行 Guanchao.exe。SHA256SUMS-0.3.0.txt 提供文件校验值。

验证：打包程序 10 项桌面检查、9 项受控首页检查通过，免安装 EXE 已在开发机启动。真实登录、真实直播连接、字段准确性和长时间运行仍待实测。二进制未做发行者代码签名。仅记录收到互动事件的观众，不提供完整在线名单或自动私信。

## English

First public release: a local Windows TikTok LIVE audience desk.

Embedded TikTok browsing, contextual room collection, up to three concurrent tasks, audience filters, observed levels, interaction records, manual follow-up, CSV export and local SQLite storage. Demo UI has been removed.

Run the portable Windows x64 EXE or extract the complete ZIP. SHA256 checksums are included.

The packaged app passed 10 desktop and 9 controlled-homepage checks; the portable EXE launched on the development machine. Real login, LIVE collection, field accuracy and long-running stability remain unverified. Binaries are unsigned. This is an interaction-based record tool, not a complete viewer-list extractor or automated messaging tool.
